# 📺 app-series

**4BA Cinematic Gold - TV Series & Seasons Module**

## Purpose
Manages TV series catalogs with season and episode organization, progress tracking, and recommendations.

## Features
- Series catalog with metadata
- Season and episode listing
- Progress tracking (watched/unwatched)
- Episode ratings
- Release schedule notifications

## Integration
This module is part of the **4BA Cinematic Gold** ecosystem and is managed through the **app-shell** gateway.

**Gateway URL:** https://ma-tv.github.io/app-shell/
**Module Route:** `series`
